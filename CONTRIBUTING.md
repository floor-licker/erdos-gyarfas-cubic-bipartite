# Contributing

Audits, independent reproductions, and narrowly scoped corrections are
welcome. Please open an issue before changing the theorem statement,
certificate format, or primary result tables.

Pull requests should include a reproduction command and update generated
outputs and `SHA256SUMS` when necessary. Do not edit generated tables or
primary results by hand.

Use Conventional Commits for commit and pull-request titles, for example
`fix: correct certificate metadata`.

Contributions retain the license applying to the modified path; see
`LICENSES/README.md`.
