# Archive

Nothing in this directory is primary evidence for the theorem.

`superseded/unreduced_root/` records the historical generation mode that
starts from the rooted star before quotienting the first augmentation
through point 1 by the root stabilizer. Its larger state and rejection
counters were once the source of an apparent discrepancy. Both principal
programs now reproduce them exactly with `--unreduced-root`, and every
completion count remains zero.

The canonical copy used by the diagnostic reproduction command remains at
`research/results/unreduced_root_counts.tsv` because that exact path is cited
in the paper and release documentation. The archived copy is byte-identical.

Provisional side-size-30 or order-60 calculations are not included in this
release and do not support a 62-vertex claim.
