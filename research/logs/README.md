# Retained logs

- `full_range/` contains fresh \(v=7,\ldots,29\) counter tables from the two
  principal implementations.
- `v29/` contains per-orbit output from all three implementations at the
  frontier.
- `certificates/` contains the expected certificate-verification summary.

These logs are secondary records. The primary machine-readable tables are
under `research/results/`, and the static proof streams are under
`research/certificates/`.
